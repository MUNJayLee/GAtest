# GAtest - 海铁联运班列调度遗传算法优化

> 基于遗传算法（Genetic Algorithm）的集装箱海铁联运班列调度优化系统，使用 MATLAB 实现。

## 项目简介

本项目针对港口集装箱海铁联运场景，使用遗传算法优化班列调度方案，综合考虑**时效性**、**经济性**和**低碳性**三大优化目标，在满足多种约束条件下寻求最优的班列开行时刻、集装箱分配方案及班列运行速度。

### 优化目标

| 目标类型 | 说明 |
|---------|------|
| **时效性** | 最小化集装箱转运时间，包括等待时间与在途时间 |
| **经济性** | 最小化总运营成本，包括班列开行成本、装卸作业成本、堆场堆存成本等 |
| **低碳性** | 最小化碳排放，包括班列运行碳排放与装卸作业碳排放 |

### 约束条件

- **维修时间窗约束**：特定时段内禁止班列开行
- **班列装载量约束**：每列班列最小/最大运载集装箱数
- **堆场容量约束**：任意时刻堆场堆存箱量不超过容量上限
- **发车间隔约束**：相邻班列发车间隔不小于最小间隔时间
- **转运时间约束**：集装箱从卸船到装车需满足最小转运时间

## 算法设计

### 染色体编码

染色体由三部分组成，总长度为 `T_max + C_max + J_max`：

| 编码段 | 长度 | 含义 |
|-------|------|------|
| `x_jdt` | T_max | 班列开行时刻与方向（0表示无班列，1~4表示方向） |
| `y_ijdc` | C_max | 集装箱分配到班列的编号（0表示未分配） |
| `v_jd` | J_max | 各班列的运行速度 |

### 遗传算法参数

| 参数 | 默认值 | 说明 |
|-----|--------|------|
| 种群规模 `pop_size` | 20 | 每代种群中的个体数量 |
| 最大迭代代数 `generation_size` | 10 | 遗传算法终止代数 |
| 交叉概率 `cross_rate` | 0.9 | 发生交叉操作的概率 |
| 变异概率 `mutate_rate` | 0.5 | 发生变异操作的概率 |
| 精英保留 `elitism` | true | 是否保留最优个体 |

### 模型参数

| 参数 | 默认值 | 说明 |
|-----|--------|------|
| `T_max` | 168 | 调度周期总长（小时，一周） |
| `J_max` | 15 | 班列总数 |
| `D0` | [1,2,3,4] | 方向集合 |
| `L_d` | [555,736,402,310] | 各方向运输距离（km） |
| `Yardcap` | 160 | 堆场容量（TEU） |
| `mintranstime` | 2 | 最小转运时间（小时） |
| `minintervaltime` | 1 | 最小发车间隔（小时） |
| `maxtsegs` | 10 | 单班列最大运载箱数 |
| `mintsegs` | 5 | 单班列最小运载箱数 |

## 快速开始

### 环境要求

- MATLAB R2016b 或更高版本
- 需支持以下工具箱：
  - 基础 MATLAB 环境
  - （可选）优化工具箱

### 运行步骤

1. 克隆或下载本项目到本地
2. 将 MATLAB 当前工作目录切换到项目文件夹
3. 确保 `数据集.xlsx` 文件位于同一目录下
4. 在命令行中运行主程序：

```matlab
GA
```

### 输出结果

运行结束后将自动生成以下可视化结果：

1. **最优适应度迭代曲线** - 展示算法收敛过程
2. **堆场堆存动态曲线** - 展示一周内堆场箱量变化
3. **关键性能指标** - 包括：
   - 最优目标函数值
   - 直取比例
   - 平均转运时间
   - 班列总成本
   - 总碳排放量
   - 各方向班列平均速度

## 数据说明

输入数据存储在 `数据集.xlsx` 中，包含以下信息：

- **班轮信息**：到港时间、各方向集装箱数量
- **集装箱信息**：来源班轮、目的方向、到港时间
- **方向统计**：各方向总集装箱数

当前数据集包含 28 艘班轮、4 个方向的集装箱运输需求。

## 算法流程

```
开始
  ↓
读取数据集（readC）
  ↓
计算班列分配数量（caltrains）
  ↓
初始化种群（initialize）
  ↓
计算初始适应度（fitness）
  ↓
┌─── 迭代循环 ───┐
│  种群排序（rank）│
│  选择操作（selection）│
│  交叉操作（crossover）│
│  变异操作（mutation）│
│  约束检验（constraints）│
│  更新最优解      │
└───────────────┘
  ↓
输出结果（result）
  ↓
结束
```
